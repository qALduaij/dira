# Dira implementation plan

**Goal:** Build a local broadcast intelligence platform with an immediately demonstrable bilingual command center and opt-in live perception.
**Architecture:** One asynchronous FastAPI process coordinates bounded ingest, hot FAISS search, durable SQLite evidence/outbox, micro-batched Qdrant writes, deterministic alerts and background reasoning. React consumes a REST snapshot plus WebSocket events. MediaMTX and model servers remain separate processes.
**Tech stack:** Python 3.12, FastAPI, Pydantic, NumPy, FAISS, Qdrant, SQLite, React, TypeScript, Vite.
**Spec:** `Private Multimodal Intelligence Architectures.md` and the user's six-step mandate. The user authorized this replacement for the missing master specification.

## Constraints and decisions
- Local-only by default. No cloud inference, telemetry, external fonts or implicit weight downloads.
- Synthetic events must be explicitly marked. Hash embeddings are demonstration mechanics, not multilingual semantic model claims.
- MPS/CUDA/CPU selected for optional local Torch encoders; FAISS CPU on macOS; native host inference for Metal.
- Durable evidence and a transactional outbox survive Qdrant outages. Hot memory, subscribers and jobs are bounded.
- Separate modality vectors, metadata filters before ranking, RRF with deduplicated hot/warm results.
- Times are timezone-aware UTC; UI and Morning Brief use Asia/Kuwait.
- Component benchmark claims in research are targets, not measurements of this implementation.
- Working directly in the user-designated fresh directory; no existing Git repository or code to isolate.

## Review focus
- Model unavailable: explicit failure or extractive fallback, never invented synthesis.
- Warm-store outage: no silent loss; bounded ingestion/backpressure and durable retry.
- Late or repeated events: valid UTC ordering, idempotent persistence, stable source references.
- Slow WebSocket consumer: bounded queue with visible resynchronization, no blocking ingestion.
- Untrusted feed content: rendered as text, treated as evidence in prompts, no commands/tools from broadcasts.
